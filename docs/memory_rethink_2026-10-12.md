# 编辑记忆方向复盘（2026-10-12）

**结论：先不设计方法。之前的核心原则（记忆必须先重投影）和"用原视频寻址"都没有经过检查，其中一部分已经和我们自己的数据矛盾。下一步用已有的实验结果查清三个事实，再决定方法往哪走。**

背景见 [analysis_survey.md](analysis_survey.md)（第 2、6、7、8 节）和 [work_summary_2026-10-07.md](work_summary_2026-10-07.md)（4.5、5 节）。

## 1. 之前思路的问题

| # | 问题 | 说明 |
|---|---|---|
| 1 | 自己的数据不支持"必须重投影"（H3） | 第一版记忆塞的就是原样记忆（保留旧镜头的空间位置），按 H3 应该出现旧布局泄漏和重影。但玩偶印花裙上的结果是"加记忆后仍是红色小碎花，与第 1 镜接近"，没有记录到重影；骑车人失败的原因是写进去的样例本身编辑很弱，与位置无关。现有证据（只有一个例子）偏向反对 H3，却一直被当作要证明的核心原则 |
| 2 | "用原视频寻址"在最需要记忆的编辑上可能不成立 | 最需要跨镜头记忆的是编辑结果不确定的情况（白 T 恤加印花、裙子加碎花）。这类编辑区域在原视频里往往是均匀、没有纹理的，各位置的原视频特征几乎一样，按原视频特征寻址会匹配到差不多的 key，取回平均值，图案被打散或抹平。原视频纹理丰富的地方（人脸、logo）对应得准，但那里编辑本来就比较确定。"原视频提供免费的对应"是整个方向的立足点（analysis_survey 2.3 节），没有检查它在哪类编辑上成立 |
| 3 | "去掉位置、按内容读"不新 | ConsiStory、StoryDiffusion 等免训练方法就是把参考 token 拼进 self-attention 靠内容匹配保持一致；StreamV2V 的 feature bank 同理。把软重投影（位置折叠）提升为方法本身，本质仍是拼接 |
| 4 | 提过的诊断在数学上不成立 | 曾提议"统计 attention 打分里位置项和内容项各占多少"。RoPE 是对 q、k 的旋转，不是在打分上加一项，不能这样拆 |
| 5 | 跳过了 H1 | "不加记忆时跨镜头不一致，且明显大于镜头内的正常波动"从未系统量过。没有它，记忆设计没有动机 |
| 6 | 没想清楚"一致"要求的是什么 | 图案、材质类编辑，观众要的是"同一件衣服"：颜色、图案风格、密度一致，不要求逐位置对应；形状、替换类编辑（牛仔帽）才需要几何上对得上。两类需要的记忆不同，之前默认都是逐位置对应 |

另外，上一版 E1 方案（位置对齐借 Warp-as-History、attention 偏置借 Closing the Loop、对应借 DINOv2 或外接框）是部件拼接，已放弃。

## 2. 新发现的并行工作

[ContextMaster](https://arxiv.org/html/2608.04956v1)（2608.04956）：训练式的流式多镜头创作模型，包含多镜头编辑，单卡 16 FPS，记忆按内容检索。"流式多镜头编辑"这个设定的新颖性下降，详见 analysis_survey 第 5 节。

## 3. 下一步：用已有结果查清三个事实

不需要新跑编辑，只用服务器上已有的输出（`maskprop_edit_v0/s15/*/*/C.mp4`、`memcheck/s15/*/*/{C,M}.mp4` 等）。脚本：`LongLive_StreamEdit/memory_facts.py`。

| 事实 | 量法 | 用到的数据 |
|---|---|---|
| A. H1：不加记忆时跨镜头不一致有多大 | 编辑区域按 chunk 切段，每段一个 CLIP 嵌入和平均 Lab 颜色。比较同一镜头内段与段的差异和不同镜头间段与段的差异；对原视频做同样计算，扣掉视角变化本身带来的差异。按编辑类型分组 | 不加记忆的输出（C） |
| B. 原样记忆是否泄漏旧布局 | M 与 C 的逐像素差，分三个区域统计：当前物体区域、"旧镜头物体所在、当前不是物体"的区域、其余背景。泄漏会让第二个区域的差明显大于第三个 | memcheck 的 C / M 对 |
| C. 原视频特征在编辑区域内能否定位 | 只跑原视频那一路的干净前向，取若干层 self-attention 的 key（加 RoPE 之前）。相邻 latent 帧之间，对编辑区域内每个 token 在上一帧区域内找最近邻，量最近邻离自身位置多远、前 5 个匹配散得多开，与随机匹配的水平比较；再按 token 所在图块的纹理强弱分组 | 原视频 + Wan 模型 |

**怎么根据结果决定方向**

| 结果 | 含义 | 方向 |
|---|---|---|
| A 中跨镜头不一致只在某类编辑上明显超出原视频本身的差异 | 问题只存在于这类编辑 | 问题范围收窄，方法只针对这类编辑 |
| A 中各类都不明显 | H1 不成立，动机不足 | 换题或换问题定义 |
| B 中没有泄漏 | H3 不成立 | 重心转到"写什么、什么时候写"：怎么判断并保住第一次编辑出来的好样子 |
| C 中低纹理区域定位接近随机 | 按原视频寻址对加图案类编辑不可行 | "这类编辑跨镜头该迁移什么"（风格统计而非逐位置内容）本身是未解决的问题，可能比重投影更值得做 |
